# Кадровый учёт малого предприятия (Вариант 11)

Клиент-серверное приложение для автоматизации кадрового учёта

## Технологии
* **Язык:** Python 3.13
* **База данных:** PostgreSQL 17
* **Библиотеки:** psycopg2, tkinter, python-docx, openpyxl, reportlab

## Функционал
* Ведение справочника сотрудников и отделов
* Создание кадровых приказов
* Поиск и фильтрация данных
* Экспорт отчетов в DOCX, XLSX, PDF
* Импорт данных из CSV
* Мобильная веб-версия (mobile.html)

## Запуск
1. Установите зависимости: `pip install -r requirements.txt` (если создадите файл)
2. Создайте базу данных `Kadr` и таблицы (скрипт `create.sql`)
3. Настройте файл `.env` с данными вашего сервера PostgreSQL
4. Запустите приложение: `python main.py`
